## Listing Tracker (primary)

**Listing Tracker - 2026 SYNC** (Google Sheets)
https://docs.google.com/spreadsheets/d/1oi9a1Xxvxia26-6dWH7BwOSGvzLt4WIL6sC1gDJ0DwU/edit

File ID: `1oi9a1Xxvxia26-6dWH7BwOSGvzLt4WIL6sC1gDJ0DwU`
Owner: brightpathpropertymanagement@gmail.com

The authoritative record of what is available and who owns it. Read this before
answering any question about rent, availability, or which agent handles a
property.

**Sheet 1, listings.** Columns: Status, Address, Type, Agent, Rent, Website,
Notes, Placement Date.

- `Status` is Active, Pending, or Placed. Only Active is available.
- `Type` is Agent or Direct.
- `Agent` blank or "Bright Path Direct" means Chris Martinez by default.
- `Notes` sometimes names a separate showing agent, for example
  "Brittany Showing agent". The showing agent is not the listing agent.
- `Website` says Live or Not on site. "Not on site" is not publicly listed yet.

**Sheet 2, agent roster.** Columns: ID, Full Name, Status, Phone, Email,
Active Agents, Notes.
